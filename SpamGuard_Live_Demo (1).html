Methodology

Built the CRISP-DM way

The project follows CRISP-DM, the standard six-step process for data mining and machine learning work, end to end.

01

Business understanding

Define the problem, confirm the goal of a transparent classifier, and set SMART objectives.

02

Data understanding

Explore the SMS Spam Collection dataset and inspect its spam/ham balance and quality.

03

Data preparation

Clean text, remove noise, de-duplicate, and split into training and test sets.

04

Modeling

Train a Bernoulli Naive Bayes classifier — the top performer in prior published studies.

05

Evaluation

Measure accuracy, precision, recall, and F1 on a held-out test set against SMART targets.

06

Deployment

Wrap the trained model in this interface, so anyone can test a message instantly.
